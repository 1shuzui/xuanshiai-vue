## 媒体上传后再发布动态

当前真实环境禁止把 `wxfile://`、`file://`、绝对临时路径等本地媒体路径发送到 `POST /api/v1/community/posts`。发布页会返回 `MEDIA_UPLOAD_REQUIRED`，避免服务器收到不可访问的设备文件。

上线前需要提供媒体上传契约：先调用生产 HTTPS 域名下的上传初始化接口（建议 `POST /api/v1/media/uploads`），获得受控上传地址或完成上传，再将返回的 HTTPS 媒体 URL 填入动态的 `images` 或 `video` 字段。生产环境必须配置已备案、可在小程序后台校验的 HTTPS API 域名；当前局域网开发地址不能作为生产域名。
