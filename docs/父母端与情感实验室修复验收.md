# 父母端与情感实验室修复验收

本次上传基于前端 origin/main 的 8ca0204，后端基于 b8da5bb。保留主线原有页面、媒体、路由和 API 配置，未纳入旧工作区的批量删除。微信小程序为最终验收端。

## 已接通的业务路径

- 父母生成邀请，本人预览授权范围并明确确认；支持查看、撤销和到期失效。过期、撤销和账号切换不能继续读取子女业务数据。
- 候选分页、私密喜欢、认识申请、双方同意后的文字聊天共用真实后端。父母入口以实际登录父母身份访问子女专属路由，服务端核验关系和权限。
- 子女资料编辑保留已核验出生年份；清晰照片由资料本人明确允许，申请和会话列表隐藏照片与附件。消息提醒是页面内提醒。
- Mock 的资料、喜欢、申请、屏蔽和设置绑定当前账号及子女并持久化。申请与额度由同一次状态变更保存，重试不重复写入或扣额。
- 情感实验室保存题目及结果文案快照，计分按 EI、SN、TF、JP 固定次序；资料只接受测试或手动确认过的 MBTI 来源。资料编辑页跳转实验室确认，首页移除硬编码的本人 MBTI。
- 补齐最新主线资料页所需的标签目录与昵称保存函数；聊天辅助功能复用聊天权限接口返回真实会话 ID。

## 本轮精简

移除恒定的后端就绪开关、总是返回空值的消息包装函数、重复的环境分支和无调用的社区导入。父母业务入口集中处理主体检查，访问状态只组装一次响应。保留服务端授权、照片过滤、双方同意、请求账号归属和事务一致性。

## 验证结果（2026-09-06）

- 前端 11 组自动化检查通过，包括 Mock 系统、父母路径、跨账号响应、申请幂等、聊天授权、情感实验室计分与资料来源。
- 后端父母/MBTI 专项 17 项通过；隔离 MySQL 端到端场景通过，含真实登录依赖、SQL、并发创建测试、撤销与消息发送竞争、本人昵称持久化与输入校验。测试不连接部署环境数据库。
- 后端全量结果为 184 通过、4 失败、14 跳过。4 项为修复前已复现的社区问题：两项路由权限枚举、一项媒体路由枚举、一项纸飞机回滚/额度退还。
