# 社区动态图片全屏预览设计

## 目标

修复社区动态图片点击无响应的问题。用户点击动态中的任意图片后，打开全屏预览；同一动态包含多张图片时，允许左右滑动切换，并能明确关闭预览。

## 方案

在 `components/XsaDynamicCard.uvue` 内实现轻量级预览层，复用动态现有的 `photos` 数组和点击索引。预览层使用 UniApp `swiper`/`swiper-item` 承载图片，使用 `mode="aspectFit"` 保持完整图片比例，并通过固定定位覆盖页面。

预览状态只属于当前动态卡片：

- `previewVisible` 控制预览层显示。
- `previewIndex` 记录当前图片索引。
- 点击图片设置索引并打开预览。
- `swiper` 变化时同步索引，支持循环前后切换。
- 点击关闭按钮或遮罩关闭；图片区域阻止冒泡，避免触发动态卡片详情跳转。
- 单图仍使用同一预览层，只是不显示多图提示。

## 边界与错误处理

只有 `photos` 非空时打开预览。索引始终限制在图片数组范围内；图片数组为空时不渲染预览层。预览层不调用 `uni.previewImage`，避免依赖平台系统预览 API 在 H5 或不同端产生不一致行为。

## 测试

沿用项目现有的 Node.js 静态回归测试，在 `tests/test-community-flow.js` 中验证组件包含：图片点击入口、预览状态、`swiper` 切换、关闭处理，以及图片点击阻止卡片冒泡。完成后运行社区测试、Mock 测试和 `git diff --check`；若环境允许，再运行 H5 构建检查。
