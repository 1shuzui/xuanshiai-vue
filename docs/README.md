## 🛠️ 技术栈

本项目使用 **uni-app x** 框架开发：

### 关于 .uvue 文件
- `.uvue` 是 uni-app x 项目的专用文件格式
- 类似 Vue 单文件组件，但使用 **UTS (UniType Script)** 语言
- 支持编译为原生代码（Android/iOS），性能更优
- 完全支持 Vue 3 的语法和特性

### 项目结构
```
xuanshiai-vue/
├── App.uvue              # 应用入口文件
├── main.uts              # 主程序入口（UTS语言）
├── manifest.json         # uni-app 配置清单
├── pages.json            # 页面路由配置
├── components/           # 组件目录（.uvue文件）
│   ├── XsaButton.uvue
│   ├── XsaCard.uvue
│   └── ...
├── pages/                # 页面目录（.uvue文件）
│   ├── index/
│   ├── profile/
│   └── ...
└── docs/                 # 本文档目录

## 📱 主要功能模块

1. **用户系统** - 注册、登录、身份认证、资料完善
2. **匹配系统** - 智能推荐、条件筛选、快速匹配
3. **社区动态** - 发布动态、互动点赞、评论分享
4. **即时通讯** - 私信聊天、语音视频、表情包
5. **红娘服务** - 专属红娘、人工推荐、线下活动
6. **会员体系** - 会员权益、充值支付、特权功能
