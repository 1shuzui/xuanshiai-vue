- 图标路径: `static/logo.png`（需准备不同尺寸图标）
- Android 需要: hdpi, xhdpi, xxhdpi, xxxhdpi
- iOS 需要: appstore, ipad, iphone (各种分辨率)

## 🔧 本地开发注意事项

1. **开发环境要求**:
   - HBuilderX 或支持 uni-app x 的 IDE
   - Node.js 环境（用于某些构建工具）

2. **首次运行**:
   ```bash
   # 如果有 package.json 依赖
   npm install
   ```

3. **运行到不同平台**:
   - H5: 直接在 HBuilderX 中运行到浏览器
   - 微信小程序: 需配置小程序开发者工具路径
   - App: 需真机或模拟器

4. **调试技巧**:
   - 使用 `console.log` 查看日志
   - 微信开发者工具的调试面板
   - Chrome DevTools（H5）

## 📝 配置文件说明

- **manifest.json** - 应用配置清单（平台配置、权限、图标等）
- **pages.json** - 页面路由配置（页面路径、导航栏样式、TabBar）
- **uni.scss** - 全局样式变量（颜色、字体、工具类）
- **App.uvue** - 应用入口文件（生命周期、全局逻辑）
- **main.uts** - 主程序入口（Vue 实例创建）
