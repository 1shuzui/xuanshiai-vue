# 宣誓爱工程配置说明

> 本文只记录当前配置，不授权修改。`manifest.json`、`pages.json` 和 `uniCloud-aliyun/` 均为受保护区域。

## 1. 应用信息

当前 `manifest.json`：

- 名称：`xuanshiai`。
- AppID 占位：`__UNI__XUANSHIAI`。
- 版本：`1.0.0`，versionCode `100`。
- Vue 版本：3。
- `uniStatistics.enable = false`。
- 开发期 `uniCloud = false`。

发布前的 AppID、版本和服务配置必须由负责人确认。

## 2. 页面与 TabBar

`pages.json` 当前注册 14 个页面：

```text
pages/index/index
pages/community/community
pages/matchmaker/matchmaker
pages/message/message
pages/profile/profile
pages/auth/login
pages/auth/register
pages/user/detail
pages/user/edit
pages/chat/detail
pages/profile/settings
pages/profile/certification
pages/profile/vip
pages/community/publish
```

5 个 Tab 为：首页、社区、牵线、消息、我的。登录与注册使用自定义导航栏。页面存在不等于完整业务已上线，成熟度见 `PROJECT_STATUS.md`。

## 3. H5

当前配置：路由模式 `hash`、base `./`、开发端口 8080、标题“宣誓爱”、模板 `index.html`。H5 用于快速调试，不替代小程序验收。

## 4. 微信小程序

- `mp-weixin.appid` 当前为空。
- `urlCheck = false` 只适合开发调试，发布前必须复核。
- 已启用 ES6 和代码压缩设置。
- 当前配置声明定位权限，文案为“用于推荐附近的用户”。该能力不是当前产品文档已确认主功能，发布前必须重新评审必要性与隐私说明。

## 5. App 预留配置

`manifest.json` 中存在相机、存储、定位、录音权限，以及相册、相机、麦克风、定位隐私文案。部分文案提到附近推荐、语音聊天和视频通话，与当前产品边界不完全一致。

这些是历史或预留配置，不代表功能已经批准。未经确认不得修改；发布 App 前必须按真实功能最小化权限。

## 6. 图标与静态资源

App 图标配置引用 `static/logo.png`，当前仓库尚无正式品牌图标。发布 App 前需要设计负责人提供合规的多尺寸图标并完成配置评审；不要使用人物肖像或临时图冒充品牌图标。

现有业务肖像位于 `static/portraits/`。

## 7. 设计色值说明

- 页面业务样式使用 `uni.scss` 中的 CSS Token。
- `pages.json` 的导航栏和 TabBar 使用平台要求的静态色值，不能直接写 CSS 变量。
- 当前平台色值与 `DESIGN.md` 的映射需要在未来设计评审中统一；不要在普通页面继续复制这些十六进制色值。

## 8. 修改流程

1. 说明产品或平台原因。
2. 获得明确授权。
3. 修改配置并同步 `AGENTS.md`、`PRODUCT.md`、`DESIGN.md` 或本文。
4. 分别验证 H5、微信小程序及涉及的目标端。
