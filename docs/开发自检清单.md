# 开发自检清单

> 用于合并、提测或交付前。更新日期：2026-07-22。

## A. 范围与需求

- [ ] 改动只发生在当前 UniApp 工程，不新增 HTML 产品实现。
- [ ] 功能符合定版 PRD（若有）与 `../PRODUCT.md`。
- [ ] 没有引入陌生人直接私信、快速滑动匹配或不透明付费。
- [ ] 范围、流程或设计发生重大变化时，相关文档已先更新。

## B. 页面与组件

- [ ] 已优先复用现有 `Xsa*` 组件。
- [ ] 使用 `../DESIGN.md` 与 `../uni.scss` 中的既有 Token。
- [ ] 没有 `window`、`document` 或浏览器 DOM 操作。
- [ ] 页面包含加载、空态、失败、重试和禁用状态。
- [ ] 320px、375/390px、428px 宽度无严重溢出。
- [ ] 关键路径已在微信开发者工具验证。

## C. 路由与配置

- [ ] Tab 跳转使用 `uni.switchTab`，普通页面使用 `uni.navigateTo`。
- [ ] 没有未经确认修改 `pages.json`、`manifest.json` 或 `uniCloud-aliyun/`。
- [ ] 没有把 H5 预览结果当作小程序验收结果。

## D. API 与 Mock

- [ ] 页面只调用 `@/api`，不直接导入 `@/mock`。
- [ ] Mock 与目标接口字段、类型、状态保持一致。
- [ ] 切换真实接口时验证鉴权、超时、错误码和失败提示。
- [ ] 没有用假成功状态掩盖认证、付费或申请认识失败。

## E. 图片、隐私与性能

- [ ] 新图片已压缩并使用正确尺寸、格式和 `mode`。
- [ ] 上传包含授权、压缩、进度、失败与重试。
- [ ] 未展示未授权联系方式、私密照片或认证原件。
- [ ] 没有无必要的新依赖或大资源进入主包。

## F. 验证

- [ ] `node tests/test-mock-system.js` 通过。
- [ ] H5 构建或预览通过。
- [ ] 微信开发者工具关键路径通过。
- [ ] 文档链接与文件路径有效。
- [ ] 从工作区根目录执行 `graphify update .` 成功。
