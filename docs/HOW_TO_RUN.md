# 如何在 HBuilderX 中运行项目

## 📝 步骤说明

### **1. 打开项目**

1. 启动 HBuilderX
2. 菜单：**文件** → **打开目录**
3. 选择：`D:\Users\ASUS\Desktop\宣誓爱\xuanshiai-vue`
4. 点击"选择文件夹"

### **2. 运行到浏览器（推荐用于开发）**

**方式 A：菜单运行**
1. 菜单：**运行** → **运行到浏览器** → **Chrome**
2. 等待编译完成
3. 浏览器会自动打开并显示首页

**方式 B：快捷键**
- Windows: `Ctrl + R` → 选择 "运行到浏览器 - Chrome"
- Mac: `Cmd + R` → 选择 "运行到浏览器 - Chrome"

### **3. 运行到微信开发者工具**

**前置条件：**
- 已安装微信开发者工具
- 在微信开发者工具中开启"服务端口"
  - 设置 → 安全设置 → 服务端口：开启

**运行步骤：**
1. 菜单：**运行** → **运行到小程序模拟器** → **微信开发者工具**
2. 首次运行会提示配置小程序 AppID（可以使用测试号）
3. 微信开发者工具会自动启动并加载项目

## ⚠️ 常见问题

### **1. 编译报错**

如果遇到类似 "找不到模块" 的错误：
```bash
# 重新安装依赖
npm install
```

### **2. 页面空白**

检查浏览器控制台（F12）是否有错误信息：
- 如果是 API 相关错误，确认 `api/config.uts` 中 `USE_MOCK = true`
- 如果是 import 错误，检查文件路径是否正确

### **3. Mock 数据没有显示**

打开浏览器控制台（F12），查看是否有：
- `📦 [Mock Request]` 日志（说明 Mock 系统正常工作）
- 错误信息（说明代码有问题）
