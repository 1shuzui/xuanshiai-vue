## 使用说明

1. 每个模块一个文件夹；每个页面一个子文件夹。
2. 页面 `README.md` 中按原思维导图层级展开：**截图在前，其后挂接的要求/改动在后**。
3. 页面图片在对应 `images/` 目录，文件名带序号，便于对照。
4. 标记为 `改动/要求` 的条目是从文案关键词（改成/新增/参考/存疑/待定等）自动高亮的。
5. **本目录已登记为定版 PRD 的分页面与截图层**，用于页面清单、界面结构与截图对照；**不是决策层**。
6. 实现前必读顺序：决策层 → 文字层 `最终版的文字需求/` → 本目录对应页面 → `AGENTS.md` / `DESIGN.md` → `xuanshiai-vue/` 代码。
7. 生产实现只在 `xuanshiai-vue/`；不要把本目录截图路径或旧 `xmind-*` 路径写进运行时代码。
