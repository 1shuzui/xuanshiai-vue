# 宣誓爱小程序 — 前端开发指南

## 第一部分：UI设计规范（瓷白青瓷 · 克制优雅）

### 1.1 整体风格定义

全链路采用"瓷白青瓷"冷调体系。视觉清爽克制、留白充裕，弱化硬质线条与厚重装饰，以低饱和青瓷绿点缀、柔化圆角、细腻冷灰光影塑造高级专业的使用体验。适配婚恋产品认真、可信、安心的调性，兼顾高级感与易用性。

### 1.2 色彩体系

| 角色 | 色值方向 | 使用场景 |
|------|----------|----------|
| 主色 | 低饱和青瓷绿 | 按钮、重点标签、选中态、CTA |
| 基底色 | 冷瓷白 / 纯净纸张 / 纯白 | 页面背景（替代纯白，降低视觉刺激） |
| 辅助色 | 冷灰蓝 / 深青绿 / 浅蓝 | 次级文字、分割线、图标描边 |
| 文字色 | 深冷灰 / 中冷灰 / 浅冷灰 | 正文、标题、辅助说明（禁用纯黑） |

**禁止事项：** 不使用高饱和暖色（橙/红/金）、生硬撞色；色彩过渡必须用柔渐变；中性色带冷色倾向（hue 180-200）。

### 1.3 图形与版式规则

| 规则 | 具体要求 |
|------|----------|
| 圆角 | 控件统一大圆角（卡片、按钮、输入框），消解尖锐感 |
| 线条 | 优先用色块/弱阴影替代实线；必须用线时选极细冷灰柔线 |
| 留白 | 模块间距充足，页面四周预留边距，避免元素拥挤 |
| 装饰 | 青瓷绿点缀 ≤10% 页面面积，低透明度使用 |
| 毛玻璃 | 弹窗、输入组件、加载态使用磨砂半透（backdrop-filter: blur） |

### 1.4 交互质感

| 交互场景 | 实现方式 |
|----------|----------|
| 按钮/卡片 | 极淡软阴影（box-shadow 低透明度冷灰），模拟柔光悬浮 |
| 点击反馈 | 轻微缩放 + 弹性缓动（ease-out / spring） |
| 页面跳转 | 舒缓柔和过渡动画，节奏舒缓 |
| 弹窗/面板 | 从底部滑入或淡入，无突兀动效 |
| 列表加载 | 骨架屏 + 淡入，避免闪烁 |

### 1.5 组件参考

- 卡片：纯白表面 + 大圆角 + 冷灰软阴影
- 按钮：圆形/胶囊形，青瓷绿主色，柔和投影
- 进度条：青瓷绿填充，圆角轨道
- 标签/徽章：低饱和色底 + 同色系文字，圆角pill形

## 第二部分：页面结构与前端实现要求

### 全局框架

```
底部导航栏（5个Tab）：首页 | 社区 | 牵线 | 消息 | 我的
```

- 每个页面右下角含"AI合拍度"悬浮图标（固定定位，不随滚动消失）
- 导航栏样式：瓷白底色，选中态用主色（青瓷绿）图标+文字，未选中为冷灰
- 全局字体：系统默认无衬线，标题深冷灰，正文中冷灰，辅助信息浅冷灰

### 2.1 首页（自救专区）

#### 顶部引导栏

| 元素 | 说明 |
|------|------|
| 推荐/广场 切换Tab | 胶囊形切换器，选中态主色填充，未选中描边 |
| 浏览记录图标 | 右上角小图标，点击进入浏览历史列表 |
| 筛选图标 | 右上角小图标，点击弹出筛选面板（底部滑入） |

#### 推荐模式（单人名片）

- 全屏卡片式展示，一次一张，左右滑动切换
- 卡片内容：头像（大图）、在线状态绿点、用户名、出生年份、职业、居住地址、婚姻情况、学历、身高、收入、MBTI、自我介绍、相册缩略图
- 资质标签：已实名 / 学历 / 单身 / 房产认证（pill徽章，低饱和绿/蓝）
- 底部操作栏（3个按钮）：喜欢（心形）、申请认识（主色CTA）、不感兴趣（X）
- 分享按钮：跳转海报生成页
- 点击头像：进入个人主页（展示动态、背景墙、个人卡片）
- 未完善资料时：页面顶部显示提示条（冷灰提示底，引导完善）
- 浏览次数限制：规定次数内可看完整信息，超出后模糊/遮挡部分字段，提示升级会员

#### 广场模式（卡片流）

- 瀑布流/列表布局，每行1-2张卡片
- 卡片上方：置顶推荐标题栏（左侧"置顶推荐"文字，右侧"我要置顶"入口）
- 每3张名片下方插入一个"会员专区"推广卡片
- 筛选搜索框：顶部固定，支持性别、城市等条件

#### 置顶付费弹窗

- 套餐选择列表（单选）：7天/19元（默认选中）、30天/50元、90天/99元、180天/150元、270天/199元
- 底部显示总价 + "确认支付"按钮（主色大按钮）

#### 筛选面板

- 底部滑入半屏面板（毛玻璃背景）
- 筛选项：性别、城市（省市区三级）、年龄范围、学历、身高、收入
- 一期为纯免费筛选；后续可分层（初级免费/高级VIP）

### 2.2 社区

#### 顶部状态栏（3个子Tab）

| Tab | 内容 |
|-----|------|
| 喜欢 | 展示已关注/已收藏用户的动态流 |
| 同城 | 顶部城市选择器（支持添加城市），展示同城合拍用户简卡 |
| 发现 | Banner轮播（话题/线下活动/纸飞机），自动+手动切换 |

#### 发现页 — Banner轮播

- 轮播组件：圆角卡片，自动播放（3-5秒），支持手动滑动
- 内容类型：话题标签入口、线下活动海报、纸飞机入口

#### 话题模块

- 点击"全部话题"：进入话题列表页（近期热门 + 更多话题）
- 点击单条话题：进入话题参与界面（查看他人参与内容 + 发布自己的）

#### 纸飞机（匿名社交）

| 功能 | 前端要求 |
|------|----------|
| 首次进入 | 弹出昵称设置弹窗（支持随机昵称生成） |
| 扔纸飞机 | 发布匿名内容（文字/语音），带投掷动画 |
| 捡纸飞机 | 3次免费次数，捡起到随机内容，用完后提示付费/任务获取 |
| 我的纸飞机 | 列表展示自己扔出的和捡到的 |
| 纸飞机设置 | 开关、隐私选项 |
| 参与形式 | 支持文字输入 + 语音录制（长按录音交互） |

#### 线下活动

- 活动列表页：海报卡片 + 活动名称 + 基础信息（日期、费用、已报名人数）
- 活动详情页：
  - 信息隔离：活动地点报名成功后才显示
  - 底部操作栏：未结束→"我要报名"→确认信息→支付→等待审核；已结束→灰色锁定"活动已结束"
  - 未支付状态可取消报名
  - 侧边悬浮"我的"按钮→个人中心
  - 支持联系客服、一键分享、回首页
- 我的活动：Tab切换（全部/报名成功/待审/被拒/已签到）

#### 用户动态

- 动态流：图文/打卡内容，支持评论、点赞、分享、关注
- 发布入口：右下角绿色加号悬浮按钮
- 点击头像：跳转发布者主页

### 2.3 牵线

#### 模块一：一对一情感咨询

**顶部横幅：** "专业红娘团队为您牵线搭桥"（青瓷绿渐变背景 + 文字）

**Tab切换：服务红娘 | 热心红娘 | AI红娘**

| Tab | 卡片内容 | 交互 |
|-----|----------|------|
| 服务红娘 | 头像、名称、签名、成功案例 | 电话图标→拨号；微信图标→弹出二维码面板（长按识别/微信号/一键退出） |
| 热心红娘 | 头像、昵称、简介 | 排行榜（金/银/铜皇冠 + 序号），点击卡片无反应 |
| AI红娘 | 对话界面 | 情感问题咨询（类聊天窗口） |

**底部通用栏：** 左下"返回首页"按钮 + 通栏红色"我要做红娘"按钮

#### 模块二：私人定制

- 页面主题："红娘一对一高端婚恋方案"
- 7大服务模块展示（图标+标题+简述的卡片列表）：
  1. 无需注册曝光（线下收集，保护隐私）
  2. 深度了解会员（红娘1v1沟通需求）
  3. 开放隐藏会员（优先匹配优质隐藏资源）
  4. 红娘为您推荐（免去自主筛选）
  5. 个人形象指导（专业外形/穿搭改造）
  6. 替双方安排见面（规划约会方案）
  7. 反馈约见结果（约会后同步对方真实印象）
- 底部CTA："申请私人定制服务"（主色大按钮）

### 2.5 我的（个人中心）

#### 顶部基础状态区

- 头像（大圆形）+ 昵称 + 积分余额（头像旁）
- 认证标识（实名/学历/工作）：昵称旁小徽章
- 资料完善度进度条（青瓷绿填充），点击进入编辑页
- 编辑资料页：头像、昵称、年龄、职业、自我介绍（最多1000字+模板+录音入口+标签多选）、照片视频管理、择偶要求设置

#### 核心互动模块（宫格/列表入口）

| 功能 | 说明 |
|------|------|
| 认识申请 | 显示剩余次数（普通每日3次），"开通VIP"+"购买套餐"两个充值入口；规则说明；双Tab（我申请的/向我申请的） |
| 我看过谁 / 谁看过我 | 双Tab切换，访客列表；"谁看过我"仅VIP可看详细 |

| 我的爆灯 | 双Tab（我给谁爆灯/谁给我爆灯） |

### 2.6 注册与登录流程

#### 登录页

- 进入小程序后弹出登录界面
- 勾选用户协议（未勾选时点击登录提示"请同意相关协议"）
- 支持：手机号登录 / 微信一键登录

#### 完善资料流程（登录后或触发特定功能时弹出）

**步骤一：安全承诺签署**
- 展示《交友安全自律承诺》→ 勾选 → 点击"我承诺"

**步骤二：注册身份选择**

| 身份 | 后续流程 |
|------|----------|
| 找对象（自己找/替子女/找搭子） | 基础资料填写 |
| 红娘招聘 | 推广红娘(99元) / 合伙人(初级999/中级1999/战略3999) / 服务红娘(跳转工作人员二维码) |

**步骤三：基础资料填写（找对象分支）**
- 性别选择 → 老家籍贯+工作地区（省市区三级联动） → 出生日期+身高（滚轮选择器） → 学历+行业+月收入+婚姻状况 → 上传头像（禁止违规图片） → 联系方式（手动填写或一键勾选手机号为微信号） → 完成

## 第三部分：前端技术要点备忘

### 关键交互模式

| 模式 | 应用场景 |
|------|----------|
| 左右滑动切换 | 推荐名片（类Tinder） |
| 底部滑入面板 | 筛选、套餐选择、二维码展示 |
| 瀑布流/卡片流 | 广场、社区动态 |
| 轮播 | 发现页Banner |
| 悬浮按钮 | AI合拍度图标、发动态加号 |
| 手风琴 | FAQ、设置项展开 |
| 骨架屏 | 列表/卡片加载态 |
| 毛玻璃弹窗 | 确认框、输入面板 |

### 会员权益前端控制点

| 权益 | 前端表现 |
|------|----------|
| 无限申请次数 | 非会员达3次后弹充值引导 |
| 查看"谁看过我" | 非会员显示数量但模糊列表，点击弹VIP引导 |
| 无痕浏览 | VIP设置开关，非VIP不显示该选项 |
| 高级筛选 | 非会员锁定部分筛选项，带锁图标 |
| 优先曝光 | 后端逻辑，前端无感知 |
| VIP标识 | 昵称旁金色/主色徽章 |
| 完整信息查看 | 超出免费次数后字段模糊+升级提示 |

### 付费触发点（前端需埋点/弹窗）

| 触发场景 | 弹窗/跳转 |
|----------|-----------|
| 申请次数用完 | 充值引导（VIP/单次套餐） |
| 点击"我要置顶" | 置顶套餐选择弹窗 |
| 爆灯操作 | 确认支付（5元/次） |
| 纸飞机次数用完 | 付费/任务获取引导 |
| 查看访客详情 | VIP开通引导 |
| 高级筛选 | VIP开通引导 |
| 私人定制申请 | 跳转客服/支付流程 |
| 红娘入驻申请 | 跳转对应支付/联系流程 |
