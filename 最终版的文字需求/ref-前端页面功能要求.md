# 宣誓爱小程序 — 前端页面功能要求

## 全局框架

底部导航栏共5个一级Tab：首页 | 社区 | 牵线 | 消息 | 我的。每个页面右下角固定一个"AI合拍度"悬浮图标，不随页面滚动消失。

---

## 一、首页

### 1.1 顶部引导栏

- 推荐 / 广场 双模式切换Tab
- 浏览记录入口（小图标，进入浏览历史列表）
- 筛选入口（小图标，弹出筛选面板）

### 1.2 推荐模式（单人名片）

- 一次展示一张用户卡片，左右滑动切换下一张
- 卡片展示字段：头像、在线状态、用户名、出生年份、职业、居住地址、婚姻情况、学历、身高、收入、MBTI、自我介绍、相册缩略图
- 资质标签：已实名 / 学历认证 / 单身认证 / 房产认证
- 底部操作按钮：喜欢（收藏至个人主页，仅自己可见）、申请认识、不感兴趣（滑动换下一张）
- 分享按钮：跳转海报生成页面
- 点击头像：进入该用户个人主页（展示背景墙、个人动态、详细卡片）
- 未完善资料时：页面顶部出现提示条，引导用户去完善
- 浏览限制：规定次数内可看完整信息，超出后部分字段遮挡/模糊，提示升级会员

### 1.3 广场模式（卡片流）

- 列表/瀑布流布局展示多张用户名片
- 卡片上方：置顶推荐标题栏（左侧"置顶推荐"文字，右侧"我要置顶"付费入口）
- 每3张名片下方插入一个"会员专区"推广卡片
- 顶部筛选搜索框

### 1.4 置顶付费功能

- 套餐列表（单选）：7天/19元（默认选中）、30天/50元、90天/99元、180天/150元、270天/199元
- 底部显示套餐总价 + "确认支付"按钮

### 1.5 筛选面板

- 筛选项：性别、城市（省市区三级）、年龄范围、学历、身高、收入
- 一期纯免费；后续可分初级筛选（免费）和高级筛选（VIP）

### 1.6 申请认识交互

- 若当前用户未完善资料 → 跳转资料完善页面
- 资料已完善 → 向对方发送申请（普通用户限制每日免费次数）
- 对方通过后，用户收到通知，可开始聊天

## 二、社区

### 2.1 顶部状态栏（3个子Tab）

| Tab | 内容 |
|-----|------|
| 喜欢 | 展示已关注/已收藏用户的动态 |
| 同城 | 顶部城市选择器（支持添加城市），展示同城合拍用户简卡+个人介绍 |
| 发现 | Banner轮播区（话题/线下活动/纸飞机），支持滑动切换和定时自动切换 |

### 2.2 话题模块

- 点击"全部话题"→ 进入近期热门话题 + 更多话题列表
- 点击单条话题 → 进入该话题参与界面（查看他人内容 + 发布自己的参与）

### 2.3 纸飞机（匿名社交）

- 首次进入需填写昵称（支持随机昵称生成）
- 扔纸飞机：发布匿名内容
- 捡纸飞机：3次免费次数，用完后提示获取方式
- 我的纸飞机：查看自己扔出的和捡到的
- 参与形式：支持文字和语音
- 纸飞机设置：相关隐私/开关选项
- 含纸飞机专属话题（匿名话题互动）

### 2.4 线下活动

**活动列表页：**
- 活动海报 + 名称 + 基础信息（日期、费用、已报名人数）

**活动详情页：**
- 基础参数展示：报名费、活动日期、已报名人数
- 信息隔离：活动地点在报名完成后才通知
- 底部操作栏逻辑：
  - 活动已结束 → 显示"活动已结束"并锁定，无法报名
  - 活动未结束 → "我要报名" → 确认个人信息 → 支付报名费 → 等待审核
  - 未支付状态下可取消报名
- 支持联系客服答疑、一键分享、回首页
- 侧边悬浮"我的"按钮 → 跳转个人中心

**我的活动：**
- Tab切换：全部 / 报名成功 / 待审 / 被拒 / 已签到

**引流活动（如单身竞争力评分）：**
- 免费参与，共15道题
- 保存页面二维码扫码进入测评
- 填写真实条件后生成评分证书
- 分地区福利：
  - 南京地区：≥60分免费兑换1次线下活动资格；≥80分免费兑换价值5000元一对一牵线服务（添加客服微信核验）
  - 非南京地区：≥60分免费领取3个月会员
- 底部"我要报名"按钮（未完善信息触发弹窗引导）

### 2.5 用户动态

- 动态流展示：支持文字/图片/打卡动态
- 互动：评论、点赞、分享、关注
- 私信改为"申请认识"，对方通过后才可互发私信
- 点击头像可查看该用户主页

### 2.6 发动态

- 绿色加号悬浮按钮，点击进入发布页
- 支持文字、图片、打卡类型

## 三、牵线

### 3.1 一对一情感咨询

**顶部横幅：** "专业红娘团队为您牵线搭桥"

**Tab切换：服务红娘 | 热心红娘 | AI红娘**

**服务红娘（付费专业红娘，1v1定制牵线）：**
- 卡片：头像、名称、个人签名、成功案例（纯展示，建立信任）
- 联系入口：
  - 电话图标 → 跳转手机拨号界面
  - 微信图标 → 弹出二维码面板（支持长按识别、微信号展示、一键退出）

**热心红娘（排行榜）：**
- 卡片：头像、昵称、个人简介
- 排行机制：按"介绍朋友数量"排序，金/银/铜皇冠 + 序号
- 点击卡片无反应（纯展示）

**AI红娘：**
- 对话式界面，可咨询情感相关问题

**底部通用栏：**
- 左下角：一键返回首页
- 通栏按钮："我要做红娘"

### 3.2 私人定制

- 页面主题："红娘一对一高端婚恋方案"
- 7大服务模块展示：
  1. 无需注册曝光（线下收集，保护隐私）
  2. 深度了解会员（红娘1v1沟通需求）
  3. 开放隐藏会员（优先匹配优质隐藏资源）
  4. 红娘为您推荐（免去自主筛选）
  5. 个人形象指导（专业外形/穿搭改造）
  6. 替双方安排见面（规划约会方案，统筹线下见面）
  7. 反馈约见结果（约会后同步对方真实印象）
- 底部核心转化按钮："申请私人定制服务"

## 五、我的（个人中心）

### 5.1 顶部基础状态

- 头像 + 昵称 + 积分余额（头像旁显示）
- 认证标识（实名/学历/工作）显示在昵称旁
- 资料完善度进度条（点击跳转编辑页）

### 5.2 编辑资料页

- 可编辑：头像、昵称、年龄、职业等基础信息
- 自我介绍：最多1000字文本（可选系统模板），提供录音入口，性格/爱好标签多选
- 照片视频：管理个人相册和视频上传
- 择偶要求：设置年龄、身高、收入、学历、职业、婚况、住房、烟酒习惯等条件，可补充额外文字说明
- 编辑完成后可预览个人主页

### 5.3 核心互动模块

**认识申请：**
- 显示剩余申请次数（普通用户每日3次）
- 提供"开通VIP"与"购买申请服务套餐"两种充值渠道
- 规则：收到申请后短信通知被申请人；对方同意则扣除1次并开放联系方式；对方拒绝则全额退还
- 双Tab切换："我申请的" / "向我申请的"

**我看过谁 / 谁看过我：**
- 双Tab切换，展示浏览足迹列表
- "谁看过我"显示访客数量，仅VIP可查看详细信息

**我的收藏：**
- 展示已收藏用户列表，仅自己可见

**我的爆灯：**
- 双Tab："我给谁爆灯" / "谁给我爆灯"

**会员充值：**
- 会员套餐选择与支付

### 5.4 个人属性与深度设置

**我的任务：**

| 任务类型 | 内容 | 奖励 |
|----------|------|------|
| 新手任务（一次性） | 双重认证（实名+学历）、上传形象照、完善资料、补充"关于我/理想型"、添加兴趣标签3-5个 | 积分/纸飞机次数 |
| 日常任务（每日） | 签到、浏览推荐、发布动态 | 积分/纸飞机次数 |
| 成长任务（周期性） | 邀请好友（注册并通过实名）、连续活跃7天 | 纸飞机次数 |

- 积分兑换区：聊天次数、小纸条群发、置顶曝光、查看访客
- 任务上方显示积分明细与提现/兑换规则

**我的动态：** 自己发布的动态列表

**我的海报：** 25款不同风格相亲海报模板（含个人资料、照片、二维码），一键生成

**我的报名：** 已报名活动列表

**诚信认证（分项入口）：**
- 实名认证
- 婚姻状态
- 单身承诺
- 学历认证
- 房产认证

**推荐给好友：** 邀请新用户可获得积分

### 5.5 客服与帮助

- 常见问题（FAQ）列表
- 意见反馈表单（收集Bug或建议）
- 人工智能客服（对话窗口）

### 5.6 设置

**账号管理：**
- 修改账号密码
- 绑定/解绑手机号（微信一键授权 + 手机号验证）
- 注销账号 / 退出登录（明确入口，符合合规要求）

**隐私设置：**
- 交友限制：可选"仅认证用户可与我交友"
- 无痕浏览：会员可开启，访问他人主页不留访客记录
- 屏蔽同事/熟人：支持屏蔽特定人群
- 状态控制：公开展示 / 委托红娘 / 完全私密 / 暂停服务 / 已脱单
- 在线设置：可公开 / 可隐藏
- 隐藏敏感信息：可隐藏学校和公司全称
- 黑名单：拉黑用户将无法访问本人资料

**消息通知：** 推送开关设置

**好评：** 跳转小程序评价页面

**安全中心：**
- 恋爱安全指南 / 防骗科普
- 一键举报入口（骚扰、虚假信息）
- 黑名单/屏蔽管理

**关于我们：** 公司介绍

**协议政策：**
- 《用户服务协议》
- 《隐私政策》
- 《交友安全承诺书》/《社区行为规范》

## 六、注册与登录流程

### 6.1 登录页

- 进入小程序后弹出登录界面
- 勾选用户协议（未勾选时点击登录提示"请同意相关协议"）
- 支持手机号登录 / 微信登录

### 6.2 完善资料流程

**触发时机：** 登录后或点击特定功能时弹出

**步骤一：安全承诺签署**
- 阅读并勾选《交友安全自律承诺》→ 点击"我承诺"进入下一步

**步骤二：注册身份选择**

| 身份分支 | 说明 |
|----------|------|
| 找对象（自己找 / 替子女登 / 找搭子） | 进入基础资料填写 |
| 红娘招聘 | 见下方红娘体系 |

**步骤三：基础资料填写（找对象分支）**
1. 选择性别
2. 选择老家籍贯、工作地区（省市区三级选择）
3. 滚轮选择出生日期、身高
4. 选择学历、工作行业、月收入区间、婚姻状况
5. 上传头像（本人清晰真实近照，禁止违规图片）
6. 联系方式：手动填写或一键勾选手机号作为微信号
7. 点击完成，结束注册

### 6.3 红娘招聘体系

| 类型 | 入口/费用 |
|------|-----------|
| 推广红娘 | 点击立即申请，99元 |
| 合伙人（初级） | 申请入伙，999元 |
| 合伙人（中级） | 申请入伙，1999元 |
| 合伙人（战略） | 申请入伙，3999元 |
| 服务红娘 | 申请后跳转工作人员二维码 |

## 八、会员权益与付费控制点

### 会员权益清单

| 权益 | 非会员表现 |
|------|------------|
| 无限申请次数 | 每日限3次，用完弹充值引导 |
| 查看"谁看过我"详情 | 仅显示数量，列表模糊，点击弹VIP引导 |
| 无痕浏览 | 不显示该设置选项 |
| 高级筛选 | 部分筛选项带锁图标，点击弹VIP引导 |
| 优先曝光 | 后端逻辑，前端无感知 |
| VIP专属标识 | 无 |
| 完整信息查看 | 超出免费次数后字段模糊 + 升级提示 |

### 付费触发点

| 场景 | 前端行为 |
|------|----------|
| 申请次数用完 | 弹窗引导（VIP / 单次套餐） |
| 点击"我要置顶" | 弹出套餐选择（5档定价） |
| 爆灯操作 | 确认支付弹窗（5元/次） |
| 纸飞机次数用完 | 引导付费或完成任务获取 |
| 查看访客详情 | VIP开通引导弹窗 |
| 高级筛选 | VIP开通引导弹窗 |
| 私人定制申请 | 跳转客服/支付流程 |
| 红娘入驻申请 | 跳转对应支付/联系流程 |
| 活动报名 | 确认信息 → 支付报名费 |
