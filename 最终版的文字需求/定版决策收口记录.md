## 3. 本期做 / 二期不做

### 3.1 本期做（C 端主路径）

- 登录注册、完善资料  
- **双重认证**：实名（公安人脸）+ 单身承诺书（电子签名）  
- 五 Tab 信息架构  
- 推荐卡片：左滑纯浏览、**收藏**；资料详情页 **喜欢**  
- 申请认识：每日免费 **3** 次；用尽后 **积分加次**（不弹 VIP / 不现金买次）  
- 私信聊天：仅双方同意后  
- 消息 / 通知  
- 社区动态  
- 纸飞机：**主流程可用**；积分解锁主页 / 兑次数等见二期  
- 牵线相关页面：**可浏览**；在线支付见二期  
- 个人中心、设置  
- 无痕浏览：**入口可见，开关不可用**，提示即将上线（不弹会员购买）  
- 谁看过我 / 我看过谁：**完整列表**，不模糊、不弹 VIP  
- 筛选：**全部筛选项开放**，不带锁、不弹 VIP  
- 积分、签到任务、邀请  
- **管理后台**（独立端）

### 3.2 二期不做（本期禁止做成可购可开主路径）

| 能力 | 本期策略 |
|---|---|
| 爆灯 | **全部隐藏**入口与文案（含交互操作、我的爆灯） |
| 会员订阅（月/季/年卡）与 VIP 开通引导 | **整块二期**；不做真实购买与开通漏斗 |
| 纸飞机 / 申请次数的商品化与现金购买 | 二期 |
| 置顶 / 付费曝光的支付 | 入口可展示，**支付关闭**（即将上线 / 不可支付） |
| 红娘 1v1 / 私人定制等在线支付 | 页面可浏览，**支付二期** |
| 纸飞机积分解锁对方主页 / 兑次数等 | 二期 |
| 无痕浏览真正可用 | 二期（本期仅占位入口） |

## 5. 关键规则展开（开发直接引用）

### 5.1 认证

- **双重认证（本期门槛语义）**  
  - 实名：公安人脸核验  
  - 单身承诺书：电子签名  
- 学历、头像等若在档案中展示，须真实状态；是否作为申请门槛以页面定稿为准，**不得**与「双重」混用未定义词。  
- 权限弹窗文案中「实名 / 双重」必须与本定义一致。

### 5.2 收藏与喜欢

| 动作 | 可见性 | 主要入口 | 说明 |
|---|---|---|---|
| 收藏 | 仅自己可见 | 推荐卡为主 | 不通知对方 |
| 喜欢 | 对对方可见的轻意向 | 资料详情页 | 非申请认识，不直接开聊 |
| 申请认识 | 正式连接请求 | 档案 / 决策点 | 双方同意后才可聊天 |

### 5.3 推荐卡片手势

- **左滑：** 仅切换下一位，纯浏览，不写负反馈。  
- **上下滑：** 查看详情。  
- **删除**「不感兴趣」能力与文案。  
- **禁止** Tinder 式左右滑匹配、爆灯等刺激玩法作为本期能力。

### 5.4 申请认识次数

- 普通用户每日免费 **3** 次；每日刷新，剩余不可跨日叠加。  
- 用尽后：走 **积分兑换 +1 次**（或等价积分加次）。  
- **禁止** 弹 VIP 开通、现金买次、默认连续包月。  
- 积分兑换单价：导图未写死 → 见第 6 节开放项，可先可配置。

### 5.5 筛选与访客

- 基础 + 高级筛选项：**本期全部可用**。  
- 谁看过我 / 我看过谁：**完整列表**，全员可看详情。  
- 不得用模糊头像 + VIP 解锁作为本期主路径。

### 5.6 无痕浏览

- 设置中保留入口。  
- 开关 **不可真正开启**。  
- 点击提示：即将上线。  
- **禁止** 跳转会员购买 / VIP 开通。

### 5.7 付费与会员（本期边界）

- 不做会员订阅购买页主流程。  
- 若界面需占位：只可「权益预告 / 即将上线」，不可假支付成功。  
- 曝光、置顶：可展示不可支付。  
- 红娘服务：可浏览预约信息，在线支付二期。  
- 任何付费均不得绕过「双方同意才可聊天」。

### 5.8 纸飞机

- 主玩法本期可用。  
- 依赖积分解锁主页、现金/商品化次数等：**二期**。
